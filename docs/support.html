空空之音 · 技术支持

需要帮助？

空空之音用于整理和播放设备本地音乐。请先查看下面的常见问题；如果仍无法解决，可以在 GitHub 项目反馈页提交问题。

扫描不到歌曲

确认歌曲文件位于应用可访问的本地位置，再在音乐管理页面重新扫描。iOS 的应用沙盒会限制可扫描的文件范围；如果仍找不到歌曲，请在 GitHub 反馈页说明文件所在位置和操作步骤。

歌曲无法播放

确认文件未损坏且格式受支持（例如 MP3、FLAC、WAV、AAC、M4A、OGG 或 WMA），然后重新扫描并尝试播放。

歌单或播放记录

歌单、收藏和播放记录保存在本机。若重装应用、清除应用数据或更换设备，本地资料可能无法自动迁移；请先备份设备数据。

联系开发者

请在GitHub 项目问题页提交功能或故障反馈。描述问题时请写明应用版本、iOS 版本、操作步骤和预期结果；请勿在公开问题中填写手机号、验证码、账户密码或其他个人信息。

本支持页不收集或处理你设备上的音乐文件或资料库内容。详见隐私政策。
